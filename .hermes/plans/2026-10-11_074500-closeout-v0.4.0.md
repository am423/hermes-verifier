def rx(words: List[str]) -> "re.Pattern[str]":

FAILURE = rx(["traceback", "error:", "failed", "exception", "no such file",

def test_the_bootstrap_resamples_sessions_not_turns():
    """Turns inside a session share an author and a project, so row-level
    resampling understates uncertainty. On a corpus where labels vary BY SESSION
    and the rule fires concentrated in a few sessions, the turn-level interval
    admitted a false survivor that the cluster interval rejected."""
    turns = []
    for s in range(10):
        rate = 0.8 if s < 3 else 0.1          # labels vary by session
        hot = s < 3                            # rule fires in a few sessions
        for i in range(40):
            turns.append({"session_id": f"s{s}", "turn": i, "calls": "", "says": "",
                          "edits": 0, "repair_next": (i % 10) < rate * 10,
                          "fire": hot})
    res = compare_rules(turns, {"ref": lambda t: t["fire"],
                                "cand": lambda t: t["fire"]},

## Risks, tradeoffs, and open questions

**The label change invalidates the loop's history.** S5 moves the base rate from 39.6%
to roughly 9.5%. Every lift, every null, and the `measured-optimization` skill's
numbers were computed against the old label. The honest move is to re-baseline and
state it, not to re-run the old experiments hoping they agree. **The loop's accumulated
decision logs survive** — they are labelled data, not derived.

**R2 changes behaviour users may rely on.** Confining `@path` imports will refuse
imports that previously worked. That is the point — but any real user with a brief that
imports across repos will see it stop. The reviewer explicitly offered "or drop `@`
imports"; confinement is the less destructive of the two, and it is what they asked
for.

**The PR push may be refused.** The account previously could not create a PR against
`NousResearch/hermes-agent`. Updating an existing branch is a different permission, but
it may also fail. Plan for a clean handoff (sha + branch + a comment draft) rather than
